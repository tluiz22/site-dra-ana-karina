# Site da Dra. Ana Karina Fernandes

Site institucional em Astro, TypeScript e Tailwind CSS para a Dra. Ana Karina Fernandes, pediatra e pneumologista pediátrica em Mossoró/RN. Os requisitos completos do projeto estão em [docs/local/demandas/requisitos](docs/local/demandas/requisitos).

## Pré-requisitos

- Node.js 22 ou superior
- npm

## Instalação

```bash
npm install
```

## Scripts disponíveis

```bash
npm run dev      # inicia o servidor de desenvolvimento
npm run build    # gera o build de produção em dist/
npm run preview  # serve o build de produção localmente
npm run check    # executa a verificação de tipos do Astro
```
